# BPM Testing Process Coverage

This module allows for coverage metrics to be obtained from running processes executed in the in-memory process engine during testing. 

## Report Generator

This library is a small viewer for process coverage reports.

To use it, just copy the build output (index.html and static folder) and replace the placeholder `{{__REPORT_JSON_PLACEHOLDER__}}` in the index.html file with the report JSON. Then you can open the file.
