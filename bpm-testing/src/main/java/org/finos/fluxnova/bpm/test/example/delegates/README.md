These are sample delegates to be used in the example process. They are not meant to be comprehensive or cover all
edge cases, but rather to provide a simple example of how to implement delegates and use them in a process.
The delegates are not available in the engine, their models cannot be deployed, and they will throw errors if executed
without being mocked in a test. They are only meant to be used in the context of testing and as examples of how to implement delegates.
